# Selected engineering work

These notes summarize projects documented in my [portfolio](https://github.com/Pratiksawan/Pratik-portfolio). They describe the application work; this repository contains profile documentation.

## MotoDock

**Purpose:** Manage workshop operations from customer intake and job cards through estimates, inventory, and billing.

**Stack:** Node.js, TypeScript, React, Prisma, PostgreSQL/SQL Server, Google Gemini, Docker.

Engineering areas described in the portfolio:

- Tenant isolation and role-based access across five roles.
- AI-assisted diagnostic reasoning and complaint summarization.
- Validation, fallback handling, and caching around AI-driven workflows.
- Transaction controls for document numbering and invoice reconciliation.
- Terminal-state restrictions for completed job cards.

[Project description in the portfolio](https://github.com/Pratiksawan/Pratik-portfolio/blob/main/data/resume.ts) · [Illustrative simulator source](https://github.com/Pratiksawan/Pratik-portfolio/blob/main/components/MotoDockSimulator.tsx)

**Public demonstration:** The portfolio simulator uses predefined cases. It demonstrates the interaction pattern and makes no live AI request. A public repository for the complete MotoDock application has not been linked.

## WhatsApp Business Chatbot Platform

**Purpose:** Support conversational business workflows through interactive WhatsApp screens and backend API integrations.

**Stack:** Node.js, Express, Meta WhatsApp Cloud API, webhooks, MySQL, Redis.

Engineering areas described in the portfolio:

- Dynamic interactive screens using Meta Flow JSON.
- Stateful conversation branching.
- Input validation and customer-data prefill.
- Fallback recovery and retries for upstream API timeouts.
- Processing form submissions through webhooks.
